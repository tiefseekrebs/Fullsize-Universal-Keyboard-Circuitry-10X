# FUKC10X — Fullsize Universal Keyboard Circuitry 10X

> 🚧 **Work in Progress** — This PCB has **not yet been prototyped** and currently has **no firmware**.
---

## Introduction

**FUKC10X** is an open-source, full-size (100%) mechanical keyboard PCB designed in KiCad. It's essentially a Daughterboard only h87 pcb with a numpad.
---


## Supported Layouts

![KLE Layout](https://i.imgur.com/VjoflkC.jpeg)

---

## Daughterboard Connector


Uses **JST SH SM04B-SRSS-TB** (4-pin, 1.0mm pitch, horizontal) — LCSC #C160404. Compatible with any daughterboard that follows the [ai03 unified daughterboard standard](https://unified-daughterboard.github.io/#/) (P01-DBxx, C4 unified, etc.).
